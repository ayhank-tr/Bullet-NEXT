# Bullet NEXT

The physics library of BGE NEXT: a frozen copy of the Bullet that Blender 2.79b ships, kept bit-identical for old games, next to a modernized Bullet (upstream base plus collision fixes, determinism, threading and a Soft Step contact solver).

- Plan: "Bullet NEXT — Master Plan" (Claude doc).
- Pinned sources: `MANIFEST.md`.
- F0 results: `docs/F0_GATE_REPORT.md`.

## Build

```
cmake -S . -B build -G Ninja
ninja -C build
python3 tools/run_f0_gate.py build gate_f0
```

C++14, strict floating point. `legacy/` is generated by `tools/rename_legacy.py` and is never edited by hand.
