# Bullet NEXT

The physics library of BGE NEXT: a frozen copy of the Bullet that Blender 2.79b ships, kept bit-identical for old games, next to a modernized Bullet (upstream base plus collision fixes, determinism, threading and a Soft Step contact solver).

- Plan: "Bullet NEXT — Master Plan" (Claude doc).
- Pinned sources: `MANIFEST.md`.
- F0 results: `docs/F0_GATE_REPORT.md`; F1 results: `docs/F1_GATE_REPORT.md`.
- Game engine wiring (2.79b): `integration/bge279/`. Chrono's Bullet copy: `integration/chrono/`.

## Build

```
cmake -S . -B build -G Ninja
ninja -C build
python3 tools/run_f0_gate.py build gate_f0
python3 tools/run_f1_gate.py build gate_f1 gate_f1/chrono_results.json
```

`BN_THREADS=<n>` runs the harness on the threaded world (as BGE NEXT does); `BN_FEATURES=<mask>`
keeps only some F1 features (benchmark B1.2). Inside another CMake project (the game engine)
only the two backends are built.

C++14, strict floating point. `legacy/` is generated by `tools/rename_legacy.py` and is never edited by hand.
